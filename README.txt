Построитель выписок — Vupisjka WPF (Win7 + .NET 6)

Состав архива (вариант B — полный):
- VupisjkaWpf.csproj — проект WPF под net6.0-windows7.0
- App.xaml / App.xaml.cs — точка входа приложения
- Папка Windows — окна интерфейса (главное окно, ключевые слова, расширенный поиск)
- Папка Services — логика чтения Excel/Word, поиска, построения выписок
- Папка Models — модели данных (строка таблицы, режимы поиска, параметры)
- Папка Themes — темы оформления (светлая, тёмная, синяя матрица, чёрно-зелёная)
- 1_build_debug_win7.bat — сборка Debug
- 2_build_release_win7.bat — сборка Release
- README.txt — эта инструкция

Требования:
- Установлен .NET 6 Runtime или SDK (подходит SDK 6.0.428, который у вас уже есть).
- Windows 7 и выше.

Как собрать EXE (вариант для пользователя, который ничего не понимает в компьютерах):

1) Распаковать архив целиком в папку (например: C:\Vupisjka_v4_5_WPF_win7).
2) Зайти в эту папку.
3) Дважды щёлкнуть по файлу:
   - 1_build_debug_win7.bat — черновая сборка, или
   - 2_build_release_win7.bat — основная сборка.

4) Откроется чёрное окно. Если в конце НЕТ красных ошибок, появится папка:
   - publish_debug_win7  или
   - publish_release_win7

5) Внутри будет файл:
   - VupisjkaWpf.exe — это и есть программа «Построитель выписок».

Этим EXE уже можно пользоваться или упаковать его в отдельный ZIP для передачи другим.

Краткая логика работы программы:
- Берёт таблицу Excel с ФИО и личными номерами.
- Читает приказы .docx из указанной папки.
- Находит совпадения по личному номеру (и по расширенным критериям, если включены).
- Определяет пункт и параграф приказа, ключевые слова (200/зачисление/увольнение/назначение/распоряжение/свои).
- Собирает выписку:
  - строит шапку: «ВЫПИСКА ИЗ ПРИКАЗА» + номер/дата (из текста или имени файла),
  - вставляет нужный § и пункт целиком,
  - находит подписантов (командир/начальник штаба и т.п.) и переносит их,
  - добавляет блок «ВЕРНО: <должность>» + звание + И.Фамилия заверителя.
- Пытается уместить всё на одной странице за счёт уменьшенного межстрочного интервала и аккуратного форматирования.
